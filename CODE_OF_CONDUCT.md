# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Its full text applies to every project space: issues, pull requests, discussions and reviews.

In short:

- Be kind and patient. Many people here are new to Vim, to open source, or to both.
- Talk about the work, not about the person.
- No harassment, no insults, no sexual language or images, no publishing of private information.

## Reporting

Report a problem in private to the maintainer, [@deafcatsteam](https://github.com/deafcatsteam),
with the contact details on their GitHub profile. To report a GitHub account, you can also use
[GitHub's report form](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

The maintainer reads every report, keeps the reporter's name private, and can remove comments,
close threads, or ban an account from the project.
