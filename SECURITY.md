# Security Policy

Insert Coin is a static website. It has no server, no accounts, no cookies and no analytics.
Progress is stored in the browser's `localStorage` and never leaves the device.

## Supported versions

Only the latest release, the one deployed on GitHub Pages, receives security fixes.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private report form: open the **Security** tab of this
repository, then click **Report a vulnerability**.

Please include the browser, the steps to reproduce, and what an attacker could do. Expect a first
answer within one week.

Useful reports include: script injection through an imported save file or a level file, and
vulnerable dependencies that reach the built site.
